# Campus Task Manager

A simple web application to manage student tasks.

## Features
- Add tasks
- View all tasks
- Delete tasks

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Developers

## How to Run
1. Clone the repository.
2. Run `npm install`.
3. Run `npm start`.
4. Open http://localhost:5000
